# OpenAI 网关控制台 v0.1.1

发布日期：2026-07-29

## 版本概述

`v0.1.1` 重点完善多渠道路由治理、运行观测和管理控制台体验，并增强单实例 SQLite 部署的运行稳定性。

## 更新内容

- 新增可配置的路由评分权重，综合价格、首 Token、响应延迟、吞吐、成功率和缓存表现选择上游渠道，并展示路由决策明细。
- 完善渠道熔断与恢复机制，支持分级熔断、自动探测和人工恢复，渠道状态及失败原因展示更加明确。
- 扩展运行总览，新增缓存命中率、官方参考费用、费用倍率，以及按渠道和模型统计的请求量、Token、成功率与费用。
- 运行总览新增可切换小时和天维度的请求折线图；查询当天时默认按小时展示，其他时间范围默认按天展示。费用倍率支持悬浮查看所选范围内占用量前五的倍率及占比，Codex 快速开始默认折叠。
- 新增熔断记录页面，支持按渠道、等级和状态筛选分级熔断事件，并允许人工重新开启被三级熔断停用的模型映射。
- 完善调用日志与会话日志，新增渠道、会话来源、渠道切换原因和结构化请求明细；优化调用量与成功率颜色提示、列表高度、内部滚动和分页布局。
- 调用日志与会话日志中的对话内容默认折叠，优先展示角色、内容摘要和字符数，并可按消息展开完整内容。
- 优化渠道与模型管理，支持列表搜索、模型映射筛选、按使用量排序、官方价格识别及常用模型自动启用，并可在系统设置中维护常用模型和路由权重。
- 路由价格与效率占比改为独立控制，质量与均衡始终使用剩余占比且至少保留 `5%`；旧权重配置会在启动时自动迁移。
- 调整性能指标口径，区分响应头延迟、首 Token 时间和响应正文耗时；同时启用 SQLite WAL、写入等待和自动空间回收配置。
